# 小玲 XiaoLing 本地模型对话助手智能体

小玲 XiaoLing 是一款本地模型对话助手智能体。

## 核心特性

**网页聊天界面 (index.html)**
支持本地 Python 后端与 Ollama 接口。

**后台运行与沙箱 (app.py)**
支持本地模型服务以及静默沙箱后台运行。

## 快速开始

**第一步：启动服务**
运行 python app.py 启动本地模型后台与静默沙箱。

**第二步：连接 Ollama**
确保本地 Ollama 服务已启动并加载所需模型。

**第三步：打开界面**
在览器中打开 index.html 网页聊界面，即可开始对话。
